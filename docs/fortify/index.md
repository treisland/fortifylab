# Fortify system

Use this section to learn what each service does and how data moves through the
lab before operating it.

The [offline Help Center](../help/README.md) is the current authoritative
component knowledge set. It covers:

- Software Security Center (SSC), the central application;
- ScanCentral SAST and ScanCentral DAST;
- License and Infrastructure Manager (LIM);
- MySQL, PostgreSQL, and Kubernetes Dashboard;
- dependencies, data flow, interfaces, roles, and terminology.

Those concise topics are intentionally usable from the terminal without a
running cluster or internet connection. The site renders the same committed
sources; it does not maintain a second copy of component facts.

Continue to [deployment](../deployment/index.md) when you understand the lab's
components and dependency order.
